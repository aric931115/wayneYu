# 活動平台

一個以校園與私人活動為核心的活動管理平台。使用者可以在活動大廳探索活動、加入活動、完成現場任務與問答挑戰；活動建立者則可以建立、管理及刪除自己的活動，讓線上資訊與實體參與流程連結在一起。

## 主要功能

### 響應式介面

- 支援手機、平板與桌面瀏覽；活動列表與任務卡片會依畫面寬度調整欄數
- 導覽列與內容區在窄螢幕會保留可用寬度，避免主要操作被擠出畫面

### 活動大廳

- 瀏覽全部、校園、私人與已加入的活動
- 查看活動名稱、類別、主題標籤、日期、時間與參與人數
- 支援活動名稱跑馬燈公告，點擊後可直接前往對應活動
- 無實體地點的活動不顯示地點標籤
- 查看活動發布者；建立者可以選擇匿名發布
- 活動建立者可透過「我的活動」快速管理自己建立的活動

### 建立活動

- 設定活動類別、名稱、開始／結束日期與時間
- 支援跨日活動
- 設定實體地點，或勾選「無實體地點」
- 設定人數上限，或選擇無人數上限
- 建立最多五個主題標籤並自訂標籤顏色
- 建立多個任務，設定完成次數與任務積分
- 任務建立在所屬活動中，但活動本身不另外設定積分；積分屬於個別任務，達成任務條件後依設定發放
- 建立任務時會說明各驗證方式與任務積分的關係
- 社交驗證會為每位參與者產生活動／任務限定碼；輸入其他參與者的碼會增加輸入者自己的任務進度，同一對象不可重複計算
- 加好友使用獨立的使用者 ID 邀請與接受流程，不要求共同參加活動，也不會影響任務驗證
- 校園活動任務積分上限為 10 分
- 可選擇建立活動房間與圖像配對遊戲
- 圖像配對遊戲每次配對積分上限為 3 分
- 可建立獨立問答題，不依賴活動房間
- 問答題支援多選正確答案，每題積分上限為 5 分
- 建立表單提供即時合理性檢查，包括日期、時間、人數、重複名稱、重複任務、重複題目與重複選項
- 建立成功後顯示活動資訊與建立者專屬代碼確認視窗

### 活動參與與任務

- 同一位使用者在同一活動只能加入一次
- 加入活動後才會顯示活動房間代碼
- 任務需輸入活動建立者提供的專屬代碼才能完成，避免自行刷分
- 顯示任務完成次數與進度條
- 問答挑戰支援多選作答與答題結果提示
- 圖像配對遊戲提供水果名稱與圖片的互動配對玩法

### 我的生涯

- 顯示總積分
- 依參加時間顯示歷史活動
- 已完成與未完成活動使用不同視覺樣式
- 點擊活動紀錄可展開查看當時的時間與地點
- 歷史紀錄只提供資訊查看，不會重新進入任務房間

### 其他功能

- 社交頁面支援獨立好友邀請、接受與好友列表
- 依目前活動功能設計的成就系統
- 積分成就會依累積總積分逐步解鎖：10 分「初露鋒芒」、30 分「積分收藏家」、60 分「任務達人」、100 分「校園傳奇」，並顯示下一個成就所需積分
- 開發模式保留展示用使用者 ID 與測試使用者資料；ID 限 1–7 碼英文字母或數字
- Supabase Email／密碼註冊與登入；會員可編輯暱稱，並讀取正式積分
- 已登入會員建立活動時，會嘗試將活動與任務寫入 Supabase；訪客及其他活動互動仍使用本機展示資料
- 語音助手與語音朗讀活動資訊
- 深色模式、高對比與文字大小設定

## 快速開始

### 安裝依賴

```bash
npm ci
```

### 啟動開發伺服器

```bash
npm run dev
```

啟動後依終端機顯示的網址開啟應用程式，通常為 `http://localhost:8080/`。

Windows 可雙擊 `start-dev.bat`；macOS 可在終端機執行 `npm ci && npm run dev`。兩個平台都依同一份 `package-lock.json` 安裝依賴。

Supabase 登入需要將 `.env.example` 複製為 `.env.local`，並填入 Supabase Project URL 與 publishable/anon key。未設定時仍可使用訪客展示流程；Supabase 登入、帳戶及雲端功能會提示需要設定。不可將 service role/secret key 放入前端環境變數。

### 建置正式版本

```bash
npm run build
```

### 預覽正式版本

```bash
npm run preview
```

### 執行測試與檢查

```bash
npm run test
npm run lint
```

## 技術架構

- **前端框架**：React 18
- **程式語言**：TypeScript
- **建置工具**：Vite
- **路由**：React Router
- **樣式系統**：Tailwind CSS
- **元件系統**：shadcn/ui、Radix UI
- **圖示**：Lucide React
- **通知提示**：Sonner
- **狀態管理**：React Context 與自訂 Hooks
- **圖表**：Recharts
- **測試工具**：Vitest、Testing Library

活動大廳、報名、任務進度、好友、遊戲及訪客資料目前仍以瀏覽器 `localStorage` 展示，不會跨裝置同步。Supabase 已用於 Email 帳號驗證、會員個人資料與積分讀取；登入會員建立活動時，活動及任務也會寫入資料庫，但目前大廳尚未讀取這些雲端活動，訪客資料也不會自動轉成會員資料。完整跨裝置活動流程及資料庫權限仍需後續整合與驗證。

## 專案結構

```text
src/
├── components/       # 共用版面與 UI 元件
│   └── ui/           # Radix/shadcn UI 元件
├── contexts/         # 全域使用者與設定狀態
├── hooks/            # 活動資料與共用功能 Hooks
├── lib/              # 工具函式
├── pages/            # 活動大廳、建立活動、任務房間等頁面
└── test/             # 測試檔案
```

## 開發流程

1. 建立功能分支。
2. 安裝依賴並啟動開發伺服器。
3. 完成功能後執行 `npm run build`、`npm run lint` 與必要測試。
4. 提交變更並建立 Pull Request。
